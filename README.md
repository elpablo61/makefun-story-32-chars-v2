One Wi-Fi network name of at most 32 characters that tells a whole story —
a divorce in a single breath.

## The entry

> **Ex Took The Kids, Not WiFi** (26 characters)

The ex took the kids. The Wi-Fi stayed. The story writes itself.

## Run

```sh
node main.ts
# writes entry.txt (26 characters, no trailing newline) to $MAKEFUN_OUTPUT_DIR or /output
```
